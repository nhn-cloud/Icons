## service-boxes

레퍼런스 아키텍처 36건에서 박스로 쓰인 근거가 있는 서비스만 Groups 팔레트에 넣었습니다(9개).
나머지는 PPT 작업용으로 남겨 둡니다. draw.io에서는 Generic Group에 서비스 아이콘을 얹어 대신 씁니다.

블랙 버전은 없습니다. 원래부터 `box_type/black`에는 그룹 컨테이너 11개만 있었습니다.
